دعم الآيفون والآيباد

مساحتك الموسيقية،
بخطوات واضحة.

MIDIForge سطح تحكّم MIDI قابل للتخصيص. ستجد هنا طريقة البداية والاتصال وحل المشكلات الشائعة.

ابدأ العزف

  1. تخطّ الجولة السريعة أو أكملها، ثم افتح «اللوحة» من الشاشة الرئيسية.
  2. جرّب أدوات اللوحة الافتراضية، أو افتح زر المجلد لتحميل قالب جاهز.
  3. اضغط زر الإضافة لاختيار أداة. افتح القفل لتحريك العناصر وتعديلها.
  4. من إعدادات الاتصال اختر منافذ MIDI المناسبة لآلتك أو برنامجك الموسيقي.

التطبيق أداة تحكّم MIDI؛ يتطلب توجيه الرسائل جهازاً أو تطبيقاً أو برنامجاً متوافقاً. لا يقدّم مكتبة أصوات مستقلة أو برنامج إنتاج موسيقي كاملاً.

الاتصال بـMIDI

USB

صِل جهاز MIDI أو واجهة متوافقة باستخدام الكابل أو المحوّل المناسب، ثم حدّث قائمة المنافذ. بعض الأجهزة تحتاج طاقة خارجية.

البلوتوث

افتح إعدادات الاتصال واختر إعداد البلوتوث أو البحث عن الأجهزة. اسمح بالبلوتوث عند طلبه، وتأكد أن الطرف الآخر يدعم Bluetooth MIDI. الاقتران الصوتي وحده لا ينشئ اتصال MIDI.

الشبكة المحلية

ضع الأجهزة على الشبكة نفسها، واسمح بالوصول للشبكة المحلية عند الحاجة. للعزف المشترك، استضف جلسة من جهاز وانضم إليها من الآخر. لإرسال OSC اضبط عنوان المضيف والمنفذ الصحيحين.

حل المشكلات الشائعة

واجهة فارغة أو شاشة سوداء

أغلق التطبيق وأعد فتحه، وتأكد أن جهازك يعمل بنظام iOS أو iPadOS 17 أو أحدث وأن لديك مساحة تخزين متاحة. إذا كانت اللوحة خالية من الأدوات، استخدم زر الإضافة أو حمّل قالباً جاهزاً. لا تحذف التطبيق قبل حفظ ما تحتاجه من إعدادات.

لا تصل رسائل MIDI

تحقق من تفعيل منفذ الإخراج ومن توافق القناة ورقم الرسالة مع الجهاز المستقبل. حدّث المنافذ، وجرّب كابلاً آخر أو أعد جلسة البلوتوث. تحقق من إعدادات MIDI في برنامج الإنتاج.

نغمة عالقة

اضغط زر الإيقاف الطارئ الأحمر لإرسال إيقاف النغمات، ثم تحقق من الاتصال والتعيين.

الأدوات لا تتسع للشاشة

فعّل ملاءمة اللوحة للشاشة من قائمة الأدوات، أو استخدم وضع التركيز لأداة واحدة. تتكيّف الواجهة مع الاتجاه ومساحة نافذة الآيباد.

الأجهزة واللغات

يتطلب MIDIForge جهاز iPhone أو iPad بنظام 17 أو أحدث. تتوفر العربية والإنجليزية والفرنسية والإسبانية في الواجهة الأساسية، ويمكن تغيير اللغة والثيم من الإعدادات. الحساسات وتعقّب الوجه وAirPods وApple Pencil تعتمد على توافق العتاد والأذونات. لا يوجد تطبيق Apple Watch مرافق موزّع حالياً.

تواصل مع الدعم

افتح طلب دعم في مستودع GitHub الرسمي. اذكر طراز الجهاز وإصدار النظام والتطبيق، وخطوات تكرار المشكلة ونوع اتصال MIDI. طلبات GitHub علنية؛ لا تنشر كلمات مرور أو بيانات شخصية أو ملفات موسيقية خاصة.

MIDIForge is a customizable MIDI control surface. Find setup help, connection guidance and solutions to common problems below.

Get started

  1. Complete or skip the quick tour, then open Canvas from the dashboard.
  2. Try the starter controls or use the folder button to load a factory preset.
  3. Use the add button to choose a control. Unlock the canvas to move and configure controls.
  4. Open connectivity settings and select the MIDI ports for your instrument or music software.

MIDIForge is a MIDI controller. Routing requires a compatible device, app or software. It is not a standalone sound library or a complete DAW.

Connect MIDI

USB

Connect compatible MIDI hardware or an interface with a suitable cable or adapter, then refresh the port list. Some devices need an external power supply.

Bluetooth

Open connectivity settings to configure Bluetooth or scan for devices. Allow Bluetooth when prompted and confirm that the other device supports Bluetooth MIDI. Audio pairing alone does not create a MIDI connection.

Local network

Connect devices to the same network and allow local-network access when needed. For a shared canvas, host a session on one device and join it from the other. For OSC, enter the correct destination host and port.

Troubleshooting

Blank interface or black screen

Close and reopen the app. Check that your device runs iOS or iPadOS 17 or later and has available storage. If your canvas has no controls, add one or load a factory preset. Save any settings you need before deleting the app.

No MIDI arrives

Check that the output port is enabled and that the channel and message number match the receiver. Refresh the ports, try a different cable or reset the Bluetooth session. Check MIDI input settings in your music software.

A note is stuck

Use the red panic button to stop notes, then check your connection and mappings.

Controls do not fit the screen

Enable fit-to-screen from the canvas tools menu or use Focus mode for one control. The interface adapts to orientation and the available iPad window space.

Devices and languages

MIDIForge requires an iPhone or iPad with iOS or iPadOS 17 or later. The main interface supports Arabic, English, French and Spanish; change language and theme in settings. Motion, face tracking, AirPods and Apple Pencil features depend on compatible hardware and permissions. A distributed companion Apple Watch app is not currently included.

Contact support

Open an issue in the official GitHub support repository. Include your device model, OS and app version, reproduction steps and MIDI connection type. GitHub issues are public: do not include passwords, personal information or private music files.
